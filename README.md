SKUD Excel VSTO Add-in — «Отделы по листам / по файлам»

Надстройка Excel (VSTO) автоматизирует разнос строк по отделам:

Отделы по листам — создаёт один файл <исходник>_по_отделам.xlsx с листами по каждому отделу (Отдел, Отдел_нет_прохода).

Отделы по файлам — создаёт отдельный файл на каждый отдел в папке <исходник>_по_отделам\ (в каждом файле 1–2 листа).

По умолчанию:

Заголовок — строка 5, данные — с 6-й.

Маркер конца блока — в колонке A значение ИТОГО.

Имя отдела — из колонки B первой строки блока.

Дата — колонка F, время — колонка G. Строки выходных с нулевым временем удаляются. Время 0:00 в G подсвечивается красным фоном (только ячейка).

При другой структуре обновите константы в модуле: HEADER_ROW, DATA_START_ROW, COL_MARKER, COL_DEPT, COL_DATE, COL_TIME.

Состав

ReportByDepartments.vb — основная логика (оба режима).

ThisAddIn.vb — точки входа для Excel.

Ribbon1.vb — 4 кнопки на ленте:

Отделы по листам: из активной книги / выбрать файл

Отделы по файлам: из активной книги / выбрать файл

(Опционально) docs/выгрузка_полная.xlsx — пример для теста.

Требования

Windows + Microsoft Excel (разрядность 32-бит или 64-бит).

.NET Framework 4.x.

VSTO Runtime (установщик подтянет сам).

Для сборки из исходников — Visual Studio (Community подойдёт) с «Office/SharePoint development».

Важно: разрядность сборки должна совпадать с разрядностью Excel у пользователя:
Excel 32-бит → сборка x86; Excel 64-бит → сборка x64.

Установка
Вариант A — из готового релиза (рекомендуется для пользователей)

Скачайте архив из Releases (папка publish_x86 или publish_x64 — в зависимости от разрядности Excel).

Закройте Excel.

Распакуйте архив и запустите Setup.exe.

Подтвердите установку. По окончании откройте Excel:

Файл → Параметры → Надстройки → Управление: COM-надстройки → Перейти…
Проверьте, что надстройка включена (галочка стоит).

Вариант B — сборка из исходников (для разработчиков)

Клонируйте репозиторий:

git clone https://github.com/<user>/<repo>.git


Откройте .sln в Visual Studio.

В Project → Properties:

Build → Platform target: x86 или x64 (под Excel).

(Опц.) Signing → Sign the ClickOnce manifests → Create Test Certificate…

Publish → Prerequisites…: отметьте .NET Framework 4.x и VSTO Runtime.

Соберите и Publish (создаст Setup.exe + .vsto).

Установите, запустив Setup.exe.

Использование

В Excel появится вкладка/группа с 4 кнопками:

Отделы по листам (активная книга)
Создаёт <имя_исходника>_по_отделам.xlsx рядом с исходной.

Отделы по листам (выбрать файл)
Запросит книгу и сделает то же.

Отделы по файлам (активная книга)
Создаёт папку <имя_исходника>_по_отделам\ и в ней файлы Отдел.xlsx. Папка откроется в Проводнике. Файлы не открываются автоматически.

Отделы по файлам (выбрать файл)
То же, но через диалог выбора.

Где искать результат: рядом с исходником. В режиме «по файлам» — в подпапке <имя_исходника>_по_отделам\.

Настройки и адаптация

Откройте ReportByDepartments.vb и при необходимости измените:

HEADER_ROW      = 5
DATA_START_ROW  = 6
COL_MARKER      = 1 ' A ("ИТОГО")
COL_DEPT        = 2 ' B
COL_DATE        = 6 ' F
COL_TIME        = 7 ' G


Имена листов режутся до 31 символа, запрещённые символы заменяются на _.
В режиме «по файлам» имена самих файлов очищаются и ограничиваются ~50 символами.

Обновление/удаление

Обновление: переустановите новую версию (ClickOnce сам заменит).

Удаление: «Приложения и возможности» / «Программы и компоненты» → удалите надстройку, либо снимите галочку в COM-надстройках Excel.

Частые проблемы

Надстройка не загружается
Проверьте разрядность (x86/x64), установите VSTO Runtime/.NET, убедитесь в разрешениях Центра управления безопасностью (Файл → Параметры → Центр → Параметры центра → Надстройки).

Конфликт .git / Visual Studio (если работаете из исходников)
Добавьте .gitignore (исключите .vs/, bin/, obj/ и т.п.).

AutoFilter COMException
В коде уже предусмотрен безопасный режим — фильтр опционален и не мешает формированию отчёта.
